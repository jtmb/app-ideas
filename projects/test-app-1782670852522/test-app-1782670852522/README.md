# Test App

A React application for managing test items.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Test

```bash
npm test
```

## Features

- List and view test items
- Search functionality
- Status badges with color coding
- Delete items
